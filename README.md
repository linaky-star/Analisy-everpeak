# Urban-mobility-productivity
 Movilidad urbana y productividad económica
 Descripción del proyecto

# Este proyecto analiza la relación entre la movilidad urbana y la productividad económica en diferentes ciudades del mundo utilizando datos de:

TomTom Traffic Index
OECD Cities

# El objetivo es identificar patrones entre congestión vehicular, tiempos de viaje y variables económicas como PIB per cápita y desempleo.

#  Objetivos
Analizar ciudades con alta congestión y baja productividad.
Identificar ciudades con mejor desempeño urbano y económico.
Explorar relaciones entre movilidad y desarrollo urbano.
Generar insights para futuras inversiones en infraestructura.

#  Principales hallazgos
Las ciudades con mayor congestión suelen presentar menores niveles de productividad.
Algunas ciudades muestran un equilibrio positivo entre movilidad eficiente y crecimiento económico.
El tiempo de viaje parece tener una relación importante con indicadores de bienestar urbano.
